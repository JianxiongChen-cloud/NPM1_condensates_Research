# NPM1_condensates_Research
Mainly research the function of NPM1 condensates in disease.

#01_NPM1_BioID_GO_analysis.R
This script identifies high-confidence NPM1-associated proteins from BioID-MS data, performs GO biological process enrichment analysis, visualizes functional modules, and extracts ribosomal proteins from the NPM1 interactome.

#plot_CPTAC_COAD_RP_heatmap.R
This script visualizes tumor-normal log2 protein abundance ratios of ribosomal proteins in CPTAC colorectal cancer proteome data.

# NPM1 Interactor Functional Module Analysis in CPTAC COAD
This repository contains R scripts for integrative analysis of NPM1-associated proteins in colorectal cancer (CRC) proteomic datasets.
## Overview
The workflow:
1. Defines functional modules from GO enrichment analysis of high-confidence NPM1 interactors.
2. Maps NPM1-associated proteins to CPTAC colorectal cancer proteomic datasets.
3. Visualizes coordinated protein abundance changes across functional modules using ComplexHeatmap.
